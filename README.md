# 📊 PR.2 Analyzer – Advanced Excel Data Analysis Project

## 📌 Project Overview

PR.2 Analyzer is an advanced Microsoft Excel project designed to analyze business sales data, identify trends, evaluate profitability, and create meaningful insights using Excel formulas, PivotTables, charts, and data analysis tools.

This project demonstrates practical Excel skills used in Data Analytics and Business Intelligence.

## 🎯 Project Objectives

- Analyze sales and profit performance.
- Identify top-performing products and customers.
- Understand monthly sales trends.
- Compare regional and product-wise performance.
- Perform descriptive statistical analysis.
- Apply regression analysis.
- Build meaningful charts and dashboards.
